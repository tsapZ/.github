# Contributing

Thanks for wanting to help! These are small fan projects, so the way in is simple: **issues only**.
Pull requests aren't taken, but every report and idea is read.

## Reporting a problem

1. In the game: **F4** (or **Back + RB** on a controller) > **Game** > **Report a problem**. It keeps
   a picture of that moment. In Core of Light: **Settings** > **Report a problem** makes a text file
   on your desktop with the logs and settings of every game (your Windows user name and the PC's
   name are taken out).
2. Open a new issue in the game's repository (or in Core of Light's for the launcher), pick the
   form, say what happened, and drag that text file into it.

The report helps a lot: it shows the game version, your disc version and what the game logged.

## Ideas

Welcome, as an issue. Say what you'd like and in which game.

## Please don't post

- game files, ISOs, figure dumps, or links to them. Everything here works with **your own** discs
  and figures, and the repositories stay free of game data;
- personal data (yours or anyone else's).

## Discs

Each game is built for one disc version, mostly the European one; its README says which. A disc
Core of Light doesn't know (for example a US disc) can't be set up yet. Tell us in an issue which
version you have, that helps to decide what comes next.

## Languages

English and German are both fine for issues. Answers come in English, short.

## How these projects are made

Almost all of the code is written by [Claude](https://claude.ai) (Claude Code); the owner decides
what gets built and tests the games. Reports from people who play are what makes it better.
