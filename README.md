# Community files

The shared community files for the Skylanders projects on this account:
[Core of Light](https://github.com/tsapZ/SkylandersCoreOfLight) (the launcher) and the six
recompiled games ([Spyro's Adventure](https://github.com/tsapZ/SSARecomp),
[Giants](https://github.com/tsapZ/GiantsRecomp), [Swap Force](https://github.com/tsapZ/SwapForceRecomp),
[Trap Team](https://github.com/tsapZ/TrapTeamRecomp),
[SuperChargers](https://github.com/tsapZ/SuperChargersRecomp),
[Imaginators](https://github.com/tsapZ/ImaginatorsRecomp)).

GitHub shows these in every repository that doesn't have its own:

- [Contributing](CONTRIBUTING.md): how to report a problem (issues only)
- [Security](SECURITY.md): how to report a security problem privately
- [Code of conduct](CODE_OF_CONDUCT.md)
- [Accessibility](ACCESSIBILITY.md): what works with a controller, a keyboard and in which languages
